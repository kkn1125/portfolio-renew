# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Backend engineering managers and technical interviewers reviewing Kim Kyeungnam's professional experience; recruiters scanning role and responsibility. The user copies the base resume into recruiting platforms and tailors it per company.

## Product Purpose

Make the developer's identity, problem-solving experience, technical judgment and operational responsibility quickly understandable, while keeping the complete career/project evidence available.

## Positioning

Real-time state management, business-data rules, legacy migration and hands-on service operations supported by actual project records and Git investigation.

## Operating Context

Korean content; desktop, laptop, tablet and mobile reading. Existing public portfolio implemented in React 19, TypeScript, Vite and MUI 9. GitHub Pages static routes generated by server/index.ts.

## Capabilities and Constraints

- Preserve Home, /portfolio, /portfolio/:company/:project and /about, and all existing project paths.
- Preserve 14 professional projects, 12 personal/team projects, career dates, factual copy, skills, contributions, issues, related projects, screenshots/video, GitHub/demo links and demo-account visibility controls.
- Resume copy is hidden: no public button/icon or command hint. Preserve only the slash -> exact copyResume -> Enter clipboard workflow and Ctrl+Shift+Alt+P printing shortcut. Hidden commands are a discoverability choice, not authentication or exclusive access.
- Preserve persisted light/dark mode and explicit theme toggle.
- Keep the current storage/models as content authority. Prior unconfirmed HIT metrics stay commented out.
- The user explicitly authorizes replacing layout, navigation and presentation components while preserving working behavior.
- No deployment or Git publication requested.

## Brand Commitments

김경남 / Kim Kyeungnam. Modern, clean, structured, technical, calm and distinctive. Avoid neon/gradient developer clichés, decorative terminals, generic SaaS hero patterns, pervasive cards and excessive animation. Use truthful content.

## Evidence on Hand

src/storage contains the revised factual resume/project records. The two Desktop source archives were the basis of the prior content revision. Existing project screenshot/media assets and profile photography are available in public/. KALIS SQL calls changed from 1+5C to 1 in one code path; do not reinterpret that as a measured response-time result.

## Product Principles

- Show problems and evidence before a broad tool list.
- Distinguish primary case studies from the full archive.
- Keep factual content intact through progressive disclosure.
- Let structure communicate growing responsibility.
- Use interaction to support exploration and comprehension.

## Accessibility & Inclusion

Keyboard navigation, visible focus, semantic HTML, contrast, reduced motion and responsive reading are required by the user. Long Korean text must remain readable at enlarged text sizes.
